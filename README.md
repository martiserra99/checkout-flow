# Checkout Flow

A Next.js project that shows how to build a checkout form with a live order summary sidebar using [Formity](https://formity.app).

The order summary sidebar updates in real time as the user moves through the form. The form also ends with a review step where each section can be edited individually before placing the order.

## What you'll learn

You'll see how to keep an outside component in sync with form values, and how `jump` combined with `variables` enables an edit-from-review pattern where users can go back to any step and return directly to the review screen.

## Getting started

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
